# USDA SSURGO capture

`akron-proof-1.json` is a real Soil Data Access response over the public Akron proof
sampling polygon. `request.json` records the endpoint, SQL, response format,
retrieval timestamp, source license and SHA-256 of the unmodified response bytes.
Source: USDA NRCS Soil Survey Staff, SSURGO via Soil Data Access; public domain
(US Government work). Survey areas and restoration dates are returned in the table.
This is survey data rather than a farmer soil test. Offline tests replay these bytes.
